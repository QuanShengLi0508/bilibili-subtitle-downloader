# 拾文发帖图片

电脑与手机图片分开保存，均为 PNG。优先使用手机 02（知乎 22 条回答与 PDF 导出）、03（转文字与四种格式）、05（文件管理）。

电脑 01、05 是实际 Windows 应用窗口；02～04 是应用界面布局测试渲染图，使用示例链接、文件名与回答数据。

手机图来自 Android 模拟器。02 中的 22 条回答与 PDF 是实际在线获取并导出的结果，重装更新后文件记录仍能恢复；04 是真实系统附件分享菜单。

微信、QQ 未安装在测试模拟器中，图 04 展示的是系统分享流程，不代表已经完成微信或 QQ 接收测试。音视频识别在 ARM64 转译模拟器的音频准备阶段未完成，仍需 ARM64 真机验证；图 03 仅展示转写界面。

电脑窗口图片含本机输出路径，布局测试图含示例内容；发帖时可按需要选用。
