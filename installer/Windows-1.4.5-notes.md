# Windows 1.4.5：知乎登录与正文完整性检查

- “知乎文本”页右上角新增“知乎登录”。在知乎官方页面手动登录，完成后关闭窗口，再重新获取正文。
- 本机独立 WebView2 会话读取知乎登录 Cookie，用于正文请求；不会上传登录会话到仓库或 Release。
- 专栏、单回答和分页回答检查接口的正文截断标记，检测到节选时停止获取与导出。
- 登录时清空旧预览，防止用户导出此前的节选。
- 安装包保持原应用标识，可覆盖旧版；登录窗口依赖系统 WebView2 Runtime。

## 验证

2026-10-02，Windows 本机：

- `cargo check --bins` 通过。
- `cargo test --bin bili-subtitle-downloader`：15 项通过，3 项在线测试按配置跳过。
- `cargo test --test zhihu_webview -- --ignored`：原生 WebView2 窗口测试通过，使用临时配置和合成 HttpOnly Cookie，确认登录 Cookie 能按网址读取，并隔离其他网站。
- 覆盖截断专栏/回答拒绝获取、完整长文末尾保留、翻页去重、文字导出和紧凑布局。

未使用真实账号自动登录；用户反馈文章登录后的实际全文需用户手动登录后确认。登录后仍返回节选时，程序会提示错误，不把节选当成全文。
