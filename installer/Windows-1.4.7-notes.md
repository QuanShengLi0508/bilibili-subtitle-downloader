# Windows 1.4.7：抖音长文章文字导出（测试版）

2026-10-05：

- “抖音下载”页增加“下载视频 / 长文章 · 导出文字”切换。
- 使用本机抖音 WebView2 会话在官方页面打开文章；用户阅读全文后点击右下角获取正文。
- 提取可见的语义文章/正文区域；未识别到正文时可手动选中文字获取，不自动拿视频文案或整页导航代替文章。
- 正文区域存在阅读全文或登录提示时停止自动提取。人工选择的文字会单独标记为选中文字。
- 先显示字数、开头与末尾，并提供全部文字预览，再确认导出 TXT、MD、Word、PDF；正文附来源链接。
- 获取预览只写临时结果文件，关闭读取窗口视为取消，不留下正式文档。

验证：
- 18 项此前测试和新增正文/导出测试通过，紧凑布局修复后对应布局测试单独通过（合计 19 项），原有 3 项在线测试跳过。
- 原生 WebView2 本地文章页面集成测试通过：执行实际页面提取脚本，保留最后一段，不包含导航/推荐文字。测试页面绕过来源限制以加载本地 fixture，生产版本保留抖音来源限制。
- 全文结果校验覆盖截断标记拒绝导出、域名边界与末尾保留。

限制：用户尚未提供真实抖音长文章分享链接，因此真实网站文章正文区域的自动识别未验证。平台只在 App 内展示或未授权的正文不能保证提取；图片文字 OCR 不包含在本次更新中。不会声称已经验证真实文章全文下载。
