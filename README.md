# 拾文

> **下载地址：** [Windows 安装包 / 免安装 ZIP（最新版）](https://github.com/QuanShengLi0508/bilibili-subtitle-downloader/releases/latest)

支持B站、抖音、小红书链接。B站可下载字幕或视频；抖音和小红书均支持配图、文案下载。小红书图文使用独立页面，小红书视频可在“下载视频”页获取。

## 使用

### 图形界面

双击项目根目录的 `拾文.exe`（或运行 `cargo run --release`）。图形版启动时不会弹出终端窗口。

1. 粘贴B站视频链接（支持 `www.bilibili.com/video/BV...`、`b23.tv` 短链接、纯 BV 号 / AV 号）。
   在链接输入框按回车也可以获取内容。
2. 在「下载字幕」和「下载视频」之间切换模式。
3. 多P视频先选分P。
4. 字幕模式：选择字幕语言，点击「下载 TXT」或「下载 SRT」。
5. 视频模式：选择清晰度，点击「下载视频」；DASH 视频会下载画面和音频，并用 ffmpeg 合并为 MP4。

文字导出可选择 TXT、Markdown、Word（.docx）或 PDF，适用于字幕、知乎文字和音视频转写；字幕与转写仍支持 SRT。Word 和 PDF 保留文字段落，并添加文档标题，PDF 自动换行分页。

文件默认保存在 `字幕输出` 文件夹，也可以在底部点击「更改」选择其他目录。保存后直接点击结果旁的「打开文件」或「打开所在位置」，无需手动寻找文件。导出为其他格式时也保留原始 TXT。
下载中会显示进度；失败的下载不会留下不完整的成品文件。

## 小红书图文（Windows 1.4.9 测试版）

顶部“小红书图文”与“抖音下载”分开。粘贴小红书笔记链接、短链接或整段分享文字，点击“获取小红书图文”。官方网页读取完成后自动返回，显示标题和图片数量；确认文案格式后，点击“保存图片和文案”。支持 TXT、MD、Word、PDF，保留作者、来源和配图顺序，保存完成后可直接打开文件夹。只提取笔记的配图和文案，不包含图片 OCR 或评论。

需要登录时可点击该页右上角“小红书登录”，在官方窗口手动登录并关闭，再获取笔记。登录会话保存在本机，与抖音会话分开。分享链接中的访问参数会保留，不把图文交给视频下载器处理。视频笔记会提示切换到“下载视频”，取消获取请关闭网页窗口。

自动检查覆盖笔记 ID、分享参数、图片来源、配图顺序、文案末尾保留及页面布局；公开笔记访问测试遇到登录要求，真实笔记完整下载仍需登录后验证。

## 抖音下载

Windows 1.4.8 支持图文分享短链接和 `/note/` 作品。进入“视频 / 图文下载”，粘贴分享文字，点击“获取抖音视频 / 图文”。图文会打开官方网页，读取作品配图与文案后自动返回；页面要求登录时请在该窗口手动登录。确认图片数量，选择文案格式，再点击“保存图片和文案”。配图按顺序保存，并保留实际图片格式；文案支持 TXT、MD、Word、PDF。保存完成可直接“打开文件夹”。取消获取请关闭网页窗口。

图文下载不把背景配乐当作视频，不包含图片 OCR，也不等于支持下述纯口令长文章。只读取所选作品的配图，不包含评论图片或推荐作品。

已在 Windows 实测分享短链 `https://v.douyin.com/364pX7G5rNs/`：正确识别作品 `7690633219121260197`，保存 1 张 WebP 配图和 TXT 文案，并核对图片、作者及来源链接。多图作品的不同页面布局仍需进一步验证。

Windows 1.4.6 新增独立的“抖音下载”页，支持视频地址、`jingxuan?modal_id=...` 精选链接、短链接，以及包含文案的整段分享文字。先获取视频信息，再点击“下载视频”，保存后可直接打开文件。

[Windows 1.4.6 安装包（测试版）](https://github.com/QuanShengLi0508/bilibili-subtitle-downloader/releases/tag/shiwen-v1.4.6)支持覆盖安装。

解析提示需要 Cookie 时，点击右上角“抖音登录”，在官方窗口访问或手动登录后关闭窗口，再重新获取。访问会话仅保存在本机，且只用于抖音请求。平台限制或下载工具不兼容仍可能导致失败；未登录实测反馈视频 `7673787196373060900` 返回 Cookie 要求，登录后的下载尚未验证。

### 抖音长文章（Windows 1.4.7 测试版）

**当前不支持“阅读文章 ^^…︽︽”这类抖音文章口令。** 用户反馈的文章仅能复制口令，测试把该口令作为短链接访问只返回抖音首页，没有打开文章。下面的功能仅适用于已有网页地址、能在网页显示正文的内容，不能据此声称已适配抖音口令长文章。

进入“抖音下载”→“长文章 · 导出文字”，粘贴分享链接，点击“打开并获取长文章”。在官方网页展开并阅读全文后，点击窗口右下角“获取文章正文”；页面未识别时，可手动选中正文后点击“获取选中文字”。返回拾文后会显示字数、开头与末尾，可点击“查看全部文字”，核对后选择 TXT、MD、Word 或 PDF，点击“确认导出文章”。获取阶段不会保存正式文档。

该功能提取网页已展示的文字，使用本机抖音 WebView2 会话。检测到正文区域仍有阅读全文/登录提示时停止自动提取。当前不包含图片 OCR，未能在网页展示的文章也无法提取；不会把视频文案自动认作文章正文。真实抖音长文章链接尚待验证，目前验证的是本地文章页面的正文识别、末尾保留及导出流程。

## B站登录（重要）

B站限制：

- **AI 自动生成的字幕必须登录后才能获取**，未登录只能下载 UP 主手动上传的 CC 字幕。
- **4K、1080P 高码率等高画质通常也需要登录**，未登录时可能只能看到 720P / 480P / 360P。

点击「扫码登录」，用B站 App 扫窗口里的二维码即可。登录成功后 Cookie 会保存在 `C:\Users\<用户名>\.bili-subtitle-cookies.json`，下次启动自动生效；点「退出登录」可清除。
扫码等待期间可以点击「取消登录」。

### 视频下载依赖

高画质B站视频通常是 DASH 格式，需要 ffmpeg 合并音视频：

```powershell
winget install Gyan.FFmpeg
```

安装后重新启动本程序。程序启动时会自动检测 ffmpeg；未检测到时会在视频模式里给出提示。

### 命令行

```text
bili-subtitle-cli.exe <链接>              # 下载第一条字幕为 TXT
bili-subtitle-cli.exe --srt <链接>        # 下载第一条字幕为 SRT
bili-subtitle-cli.exe --streams <链接>    # 查看可用画质
bili-subtitle-cli.exe --video <链接> [qn] # 下载视频，默认最高画质
```

例如查看画质后下载 1080P（清晰度 ID 为 80）：

```text
bili-subtitle-cli.exe --streams BV1xxxxxxxx
bili-subtitle-cli.exe --video BV1xxxxxxxx 80
```

## 知乎 / 网页文本

Windows 1.4.5 起，在“知乎文本”页右上角点击“知乎登录”，在独立的知乎官方窗口中手动登录，完成后关闭登录窗口，再重新获取文章。登录状态保存在本机应用数据目录。平台返回节选时会明确提示并阻止导出，不把节选当成全文。

[Windows 1.4.5 安装版](https://github.com/QuanShengLi0508/bilibili-subtitle-downloader/releases/tag/shiwen-v1.4.5)可覆盖安装。知乎登录窗口需要 Microsoft Edge WebView2 Runtime；如系统缺少该组件，程序会提示安装。

选择「知乎文本」模式，粘贴知乎问题、回答或专栏链接，先点击「获取内容」查看回答数量，再填写导出范围、选择格式，点击「确认导出」。获取时仅缓存在内存中，确认导出后才保存文件。回答链接默认导出所属问题的全部回答，包含页面下方的「更多回答」；也可选择「仅链接中的回答」。程序会逐页获取回答并去重，支持指定起止序号，保存后显示回答总数及导出范围。批量文件名带回答范围，避免覆盖单条回答文件。专栏链接只导出文章正文。



## 音频/视频转文字

在图形界面选择「音频/视频转文字」模式，选择本地音频或视频文件后点击「开始识别」。程序会用 ffmpeg 提取 16kHz 单声道音频，然后用内置的 whisper-cli 生成 TXT 和 SRT。

- 程序自动使用内置识别模型，无需选择模型文件。
- 识别默认使用自动语言检测，也可以手动选择中文或 English。
- 音频和文件只在本地处理，不会上传到服务器。
## 构建

需要 Rust 工具链。在 PowerShell 中执行：

```powershell
.\build-release.ps1
```

脚本会更新根目录的图形版、命令行版和 `release-package` 目录；若要生成安装包，再用 Inno Setup 编译 `installer/installer.iss`。

### 第三方组件

- 抖音 / 小红书下载使用 [yt-dlp](https://github.com/yt-dlp/yt-dlp)。安装包里已包含 `tools/yt-dlp.exe`；如果自己编译，请从 yt-dlp 的 Release 页下载该文件并放到 `tools/yt-dlp.exe`。
- 本地语音识别使用 [whisper.cpp](https://github.com/ggml-org/whisper.cpp)。安装包里已包含 `whisper-cli.exe` 和基础模型；如果自己编译，也需要把对应文件放到 `whisper/` 文件夹。

### Windows 1.5.1 YouTube

YouTube 独立入口提供「下载视频」和「提取字幕」，支持 watch、Shorts、live、embed 与 youtu.be 分享链接，每次处理一个视频。先获取视频和字幕列表，再下载视频或选择语言导出。作者字幕与自动字幕分别显示，字幕支持 TXT、MD、Word、PDF，并另存 SRT。

在线实测遇到 YouTube 的「登录以确认不是机器人」限制，本次尚未验证真实视频或字幕下载成功；链接规范化、字幕语言解析、JSON3 末段与时间轴、Cookie 域名过滤及界面布局通过自动检查。仅电脑版更新。
